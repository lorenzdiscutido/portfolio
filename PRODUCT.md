# Product Context & Vision: Jose Lorenzo Discutido Portfolio

## 1. Product Summary
- **Product Name**: Systems & Data Engineering Portfolio
- **Owner**: Jose Lorenzo Discutido (Lorenz)
- **Primary Domain**: Systems Engineering, IoT & Cyber-Physical Systems, Big Data Analytics, Cloud Infrastructure
- **Surface Type**: Developer Portfolio & Interactive Engineering Console
- **Stack**: Next.js 14 App Router, TypeScript, Tailwind CSS, Framer Motion, Jest

## 2. Target Audience & Personas
- **Technical Recruiters & Talent Partners**: Need immediate clarity on core competencies (Python, Dart/Flutter, Next.js, C++/IoT, MySQL, Firebase) with zero fluff and instant access to verifiable case studies and resume PDF.
- **Engineering Directors & Infrastructure Leads**: Value first-principles engineering, empirical rigor (ISO/IEC 25010 audits, time-motion studies, active-active MySQL meshes over Tailscale), clean architecture, and systems thinking.
- **Hardware & IoT Co-Designers**: Inspect schematics, microcontroller firmwares (ESP32, Arduino, UART reed interlocks), and real-time civic/enterprise dashboards.

## 3. Product Voice & Narrative
- **Tone**: Methodical, empirical, zero-trust, authoritative, calm.
- **Brand Identity**: "Stealth Terminal CLI" aesthetic combined with clean modern web GUI.
- **Core Value Proposition**: "I build end-to-end ecosystems. From cyber-physical hardware and real-time mobile dashboards to AI-driven data pipelines, I specialize in architecting scalable infrastructure that bridges the physical and digital divide."
- **Strict Anti-Patterns**:
  - No marketing clichés, buzzwords, or "AI slop".
  - No generic templates or purple-to-blue SaaS gradients.
  - No emoji icons in buttons or controls (use SVG icons).
  - No fake broken CLI links (`[ ./home ]`); use clean, semantic, accessible navigation.
  - No horizontal viewport overflow on any mobile viewport (down to 320px).

## 4. Key Interactive Capabilities
- **Dual-Mode Navigation**: Clean, accessible desktop and mobile top navigation paired with an optional, fully featured interactive CLI terminal (`Ctrl+\`` or `>_` trigger).
- **Interactive Terminal Engine**: Features real-time simulation, `whoami`, `skills`, `projects`, `ping` with active-active mesh simulation, secret unlocks, and mobile quick-command touch shortcuts.
- **Comprehensive Case Studies**:
  - *Vonotec Enterprise Infrastructure*: Active-active MySQL cluster over Tailnet with MSAL OAuth and Streamlit defect logging.
  - *IsKiosk Document Management*: Microcontroller-driven kiosk terminal with physical reed interlock and ISO/IEC 25010 empirical QA evaluation (3.70/4.00, 91.4% throughput improvement).
  - *Komunikonek Barangay Digital Hub*: Flutter/Dart mobile citizen hub with Firestore real-time streams and 9:16 mobile gallery walkthrough.
